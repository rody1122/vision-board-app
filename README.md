# Vision Board

## 概要
Vision Board は、画像を自由に配置してオリジナルのビジョンボードを作成できる Web アプリケーションです。

職業訓練でのグループ制作として開発しました。
訓練修了後は、個人で機能改善、UI・UXの見直し、バグ修正、リファクタリングを継続しています。

## 担当
### 職業訓練中
- ログイン・新規登録・ログアウト
- セッション管理
- user_id を利用したデータ取得・更新
- 画像アップロード
- 保存ボタンのAjax化
- save_position.php の実装
- 保存処理の改善
- 画像倉庫の取得条件変更

### 訓練修了後
- 編集画面のUI・操作フロー改善
- 保存処理とキャンセル処理の見直し
- `note_id` の引き継ぎ処理を修正
- 新規未保存ボードが残る不具合を修正
- キャンセル後の遷移先を整理
- 画像とスタンプの保存・削除処理を改善
- 画像の初期表示サイズを調整
- `notes` テーブルに保存状態を管理する `is_saved` カラムを追加
- JavaScript、PHPのリファクタリング
- バグ修正と動作確認

## 改善で意識したこと
グループ制作時の機能をそのまま残すのではなく、保存やキャンセル時の処理、画面遷移、画像・スタンプの扱いを見直しました。

特に、画面上では正しく動いているように見えても、データベースに不要なデータが残ることがあったため、JavaScript、PHP、MySQLの処理を確認しながら修正しました。
