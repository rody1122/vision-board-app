# Vision Board

## 概要
Vision Board は、画像を自由に配置してオリジナルのビジョンボードを作成できる Web アプリケーションです。

職業訓練でのグループ制作として開発しました。
訓練修了後は、個人で保存処理や画面遷移を見直し、ユーザーが自然に操作できることを意識しながら改善を続けています。

## 担当
### 職業訓練中
- ログイン・新規登録・ログアウト
- セッション管理
- `user_id`を利用したデータ取得・更新
- 画像アップロード
- 保存ボタンのAjax化
- `save_position.php`の実装
- 画像倉庫の取得条件変更

### 訓練修了後
- 編集画面のUI・操作フロー改善
- 保存処理とキャンセル処理の見直し
- 画像とスタンプの保存・削除処理を改善
- `note_id`の引き継ぎ処理を修正
- 新規未保存ボードが残る不具合を修正
- キャンセル後の遷移先を整理
- 画像の初期表示サイズを調整
- `notes`テーブルに保存状態を管理する`is_saved`カラムを追加
- JavaScript、PHPのリファクタリング
- バグ修正

## 改善で意識したこと
グループ制作時の機能をそのまま残すのではなく、保存やキャンセル処理、画面遷移、画像・スタンプの扱いを見直し、より自然に操作できるよう改善を続けました。
特に、画面上では正しく動作していてもデータベースに不要なデータが残るケースがあったため、JavaScript、PHP、MySQLの処理を確認しながら原因を特定し、保存処理やデータ管理を改善しました。
